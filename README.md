# Healthcare Monitoring & Alert System

## About the Project

A Python-based healthcare monitoring system developed as part of the Python for Data Analytics – I coursework at CHRIST (Deemed to be University).

The system monitors multiple health and lifestyle parameters and generates alerts when values fall outside predefined ranges.

## Project Date

September 2025

## Features

- Monitors blood pressure, heart rate, blood sugar, BMI, oxygen level, sleep duration, and water intake
- Validates user inputs and handles invalid entries
- Supports both predefined sample data and user-provided data
- Generates alerts for abnormal readings
- Produces a final health status report

## Technologies

- Python
- Conditional Statements
- Functions
- Dictionaries
- Input Validation
- Error Handling
